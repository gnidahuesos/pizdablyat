# LocalVault Desktop UI (React)

React glassmorphism shell for the LocalVault desktop app (Tauri/Electron ready).

## Запуск для чайников
1. Самый простой вариант без сервера и интернета: откройте файл `ui/preview.html` двойным кликом.
2. Для разработки установите **Node.js LTS** с https://nodejs.org (в комплекте будет npm).
3. Откройте терминал и выполните:
   ```bash
   cd ui
   npm install
   npm run dev
   ```
4. Откройте ссылку из терминала (обычно `http://localhost:5173`).

> Note: In this environment, npm registry access may be blocked. If installs fail, run in a local dev machine.
